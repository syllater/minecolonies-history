# Project Goal

Build **Imperium: European Realms** as a real Minecraft Java Edition 1.21.1 NeoForge mod that extends MineColonies with a European empire simulation.

The long-term target is:

- a successful Gradle build,
- a generated mod JAR,
- a verified attempt to start the development client with `./gradlew runClient`,
- server-authoritative gameplay,
- MineColonies as a required runtime dependency,
- Structurize integration for building/schematic work,
- BlockUI integration where the chosen versions and APIs support it,
- English and Dutch translations,
- no runtime dependency on external AI API keys.

Work proceeds by milestones. After each milestone reaches its acceptance criteria, document the evidence, update checkpoints, and ask the user for approval before starting the next major milestone.
