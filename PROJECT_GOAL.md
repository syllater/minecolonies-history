# Project Goal

Build **Imperium: European Realms** as a real Minecraft Java Edition 1.21.1 NeoForge mod that extends MineColonies with a European empire simulation.

## Long-term target

- Successful Gradle build and generated mod JAR.
- Verified development-client start with `./gradlew runClient`.
- Server-authoritative singleplayer and multiplayer gameplay.
- MineColonies as a required dependency, with Structurize building/schematic integration and BlockUI integration where supported.
- English and Dutch translations.
- No external AI API keys or runtime AI-service dependency.
- Politics, economy, diplomacy, military strategy, provincial simulation, five-level buildings and release documentation.

## Development mode

The owner explicitly instructed on 2026-10-10 that development should continue across all milestones without stopping to request approval at every milestone boundary. Continue implementing the next missing high-value functionality, run CI and fix blocking failures, and preserve a clear checkpoint trail.

This does not authorize falsely claiming completion, merging the branch, or publishing a release without permission. Never claim a test/playtest passed without evidence. Keep in-world survival/save-reload and two-player multiplayer acceptance gaps explicit until actually tested.
